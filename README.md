# Liia iOS Developer Portfolio

A custom-coded responsive portfolio website inspired by the design screenshot. It uses plain HTML, CSS and JavaScript — no Framer or Webflow.

## Files
- `index.html` — portfolio, services, starting prices, contact form
- `styles.css` — visual design and responsive layout
- `script.js` — mobile menu and email form
- `liia-portrait.png` — portrait provided for the website
- `terms.html` — editable Terms of Service template
- `privacy.html` — editable Privacy Policy template

## Before publishing
1. Review all service prices. They are example starting prices, not a binding quote.
2. Confirm that the project ownership, cancellation, confidentiality and liability terms fit how you intend to work. These are starter templates, not legal advice.
3. Confirm the privacy policy matches your final host and any tools you add.
4. Verify project details and the App Store link.
5. Add a working form backend later if you want enquiries submitted without opening the visitor's email app.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository and upload these files to its root.
2. In repository Settings → Pages, publish from the `main` branch and `/ (root)`.
3. After publication, connect your custom domain in Settings → Pages and configure DNS at your domain registrar.

GitHub Pages hosting is free for public repositories. A custom `.com` domain is paid separately.
